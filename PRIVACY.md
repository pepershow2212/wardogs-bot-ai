# Политика конфиденциальности WARDOGS BOT AI

Этот бот работает только как официальное приложение Discord (Bot API). Он не использует пользовательские аккаунты и self-bot.

## Какие данные обрабатываются

- Текст, который пользователь сам отправил боту: слэш-команда, контекстное меню, упоминание или ответ на сообщение бота.
- Небольшой контекст последних сообщений канала (5–10), только чтобы ответить на текущий запрос.
- Короткая память диалога (4–6 реплик) в оперативной памяти процесса, отдельно для пользователя и канала. Через 20 минут она исчезает. На диск не пишется.
- Идентификатор пользователя используется в оперативной памяти для антиспам-лимита и очереди.
- Публичные закрепы, посты форума базы знаний/гайдов и факты из `/fact` (включая текстовые файлы) сохраняются локально в `knowledge/`, чтобы бот мог помогать по серверу.

Бот **не** записывает личную переписку всех каналов, **не** читает тикеты/мод-логи/админ-каналы, **не** собирает presence, список друзей или платёжные данные.

## Зачем это нужно

Чтобы ответить на вопрос, суммировать обсуждение, перевести текст или напомнить публичные правила сервера.

## Кому передаются данные

Текст запроса отправляется провайдеру языковой модели, указанному в настройках бота (OpenAI-совместимый API). Discord получает только ответ бота через официальный API.

## Сколько хранится

Локально личные сообщения не пишутся в файлы. Контекст канала живёт только на время одного ответа. Память диалога и антиспам-счётчик держатся в RAM и сами истекают. Публичные гайды и `/fact` лежат в `knowledge/` на диске бота.

## Чего бот не делает

- не читает приватные админ-каналы из списка `ADMIN_CHANNEL_IDS`;
- может быть ограничен белым списком `ALLOWED_CHANNEL_IDS`;
- не отвечает в каждом сообщении чата;
- по умолчанию не работает в личных сообщениях;
- не отправляет массовые личные сообщения;
- не просит токены, пароли и коды;
- не помогает нарушать правила Discord.

## Как удалить данные / отказаться

Перестань писать боту и выгони приложение с сервера. Если нужно удалить данные у провайдера ИИ, обратись к администрации сервера.

Контакты: администрация Discord-сервера WARDOGS.
